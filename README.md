# Portfolio Grażyny Długosz

Vue 3, Vite i JavaScript. Ciemny układ inspirowany dostarczonym wzorem; efekty świetlne są wykonane w CSS.

Uruchomienie: `npm install`, następnie `npm run dev`.
Budowanie: `npm run build`. Podgląd produkcyjny: `npm run preview`.

`src/App.vue`: treść, menu mobilne, wybór kart i okno szczegółów projektu.
`src/neon.css`: układ, gradienty, neonowe efekty i reguły dla telefonu.
`src/main.js`: import aktywnych stylów.
`index.html`: tytuł i opis strony.

Brakujące informacje są oznaczone „Do uzupełnienia”. Karty to miejsca na rzeczywiste projekty; strona nie zawiera fikcyjnych adresów ani danych kontaktowych. Stare pliki `src/portfolio.css` i `src/style.css` nie są używane.
